
# Elevvo NLP Internship – Projects Portfolio

This repository contains the projects completed during my **Natural Language Processing (NLP) Internship at Elevvo**.

The projects cover different NLP and Machine Learning tasks, including sentiment analysis, news classification, fake news detection, and Named Entity Recognition (NER).

## Internship Overview

- **Organization:** Elevvo
- **Domain:** Natural Language Processing (NLP)
- **Internship Type:** One-Month Internship
- **Projects Completed:** 4

## Projects

### Task 01: Sentiment Analysis on IMDb Movie Reviews

**Objective:**  
Build a machine learning model to classify IMDb movie reviews as Positive or Negative.

**Technologies Used:**
- Python
- Pandas
- NumPy
- Matplotlib
- NLTK
- Scikit-learn

**Results:**

| Metric | Result |
|---|---:|
| Accuracy | 89.80% |
| Weighted F1-Score | 0.90 |

### Task 03: Fake News Detection

**Objective:**  
Build machine learning models to classify news statements into Fake and Real categories using the LIAR dataset.

**Dataset:** LIAR Dataset

**Technologies Used:**
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- TF-IDF
- Logistic Regression
- Multinomial Naive Bayes

**Results:**

| Model | Accuracy | Weighted F1-Score |
|---|---:|---:|
| Logistic Regression | 61.42% | 0.60 |
| Multinomial Naive Bayes | 61.50% | 0.58 |

Naive Bayes achieved slightly higher accuracy, while Logistic Regression achieved a higher weighted F1-score.

**Project:** `Task-03-Fake-News-Detection`

[View Task 03 README](Task-03-Fake-News-Detection/README.md)

---

### Task 04: Named Entity Recognition (NER) from News Articles

**Objective:**  
Identify and extract named entities such as people, organizations, locations, and dates from news articles using model-based and rule-based approaches.

**Technologies Used:**
- Python
- spaCy
- Pandas
- Matplotlib
- Seaborn
- EntityRuler
- displaCy

**Results:**

| Approach | Extracted Entities |
|---|---:|
| Model-Based NER | 14 |
| Rule-Based NER | 13 |

The project also includes entity visualization, category distribution, and a custom news article example.

**Project:** `Task-04-Named-Entity-Recognition`

[View Task 04 README](Task-04-Named-Entity-Recognition/README.md)
